# Glossary

The game is Achik Pukllay ("light game" in Kichwa), a bingo inspired by Lotería for learning Kichwa. One row per game concept: the stem code uses, and the words copy uses. Code and copy differ on purpose in three places: the caller is `host` in code and the Kawak on screen, a mark is a bean on screen, and a claim is shouted as ACHIK PUKLLAY.

## The table, not the phone

Achik Pukllay is played in person. These rules hold in every layer.

| Rule                                                                                                                                                                                                                | Where it is kept                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Players hear the cards from the caller. A player's view carries only the latest call (`last`), for a player who missed it, never the ones before it, not even hidden ones a curious player could read from the page | `PlayerViewSchema` (`packages/core/src/protocol.ts:108-120`); `hub.test.ts`, "sends a player the latest call only, never the ones before it" |
| A player may put a bean on any card of their tabla, called or not                                                                                                                                                   | `toggleMark` (`game.ts:129-143`); `game.test.ts`, "accepts a card not yet called"                                                            |
| The caller picks the rule before the first card; a new game plays for a line and then a full tabla, and a new round keeps the last rule. Players are told the rule and the prize in play                            | `setRule`, `newGame`, `newRound` (`game.ts`); `PlayerViewSchema` carries `rule` and `prize`                                                  |
| Prizes are won one at a time, in the rule's order. Granting one drops every other waiting claim and play goes on for the next; the round is over once every prize is won                                            | `grantClaim`, `prizeInPlay` (`game.ts`); `game.test.ts`, "plays a line, then a full tabla"                                                   |
| A player may win more than one prize. Whether a repeat winner takes another is the caller's call; the caller sees how many they have won                                                                            | `Player.wins`; the "Already won" badge in `claimHtml`                                                                                        |
| ACHIK PUKLLAY! only puts a claim in front of the caller; nothing is decided                                                                                                                                         | `claimWin` (`game.ts:146-151`)                                                                                                               |
| A claim wins only on cells every card of which was both marked and called: every cell, or one line, as the rule says                                                                                                | `winningCells` (`tabla.ts:58-72`), `grantClaim`                                                                                              |
| The caller can grant only a claim that wins under the rule, and can turn down only one that does not                                                                                                                | `hostActionHtml` (`render.ts:561-581`); `grantClaim` refuses with `no-win`                                                                   |
| A waiting claim holds the deck and the claimant's tabla                                                                                                                                                             | `drawCard`, `toggleMark` refuse with `claim-pending`                                                                                         |
| The player gets no verdict until the caller rules                                                                                                                                                                   | `playerView` reports `pending`; `playerAnnouncement` says only "Sent to the Kawak…"                                                          |
| Once a prize is granted, everyone sees the winner's tabla so the table can check it                                                                                                                                 | `prizesView` (`protocol.ts`)                                                                                                                 |
